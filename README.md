# Client-Side E-Commerce App

An **Angular client-side E-Commerce application** built to consume and interact with the **ASP.NET Core E-Commerce Web API** that I developed.

## 🔗 Backend API

This application consumes the E-Commerce API developed with **ASP.NET Core Web API**.

**Backend Repository:**
https://github.com/Moataz-Mohamed22/Ecommerce-App-.NET-8-And-Angular

## 🚀 Features

* 🏠 Home Page
* 🛍️ Product Listing
* 🔎 Product Search
* 🗂️ Filter Products by Category
* 💰 Sort Products by Price
* 📄 Pagination
* 🔄 Multiple Filtering & Sorting
* 📱 Responsive UI
* 🔌 Integration with ASP.NET Core Web API

## 🛠️ Technologies

* Angular
* TypeScript
* HTML5
* CSS3
* Bootstrap 5
* RESTful APIs
* ASP.NET Core Web API

## ⚙️ Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the development server

```bash
ng serve
```

Then open:

```text
http://localhost:4200/
```

The application will automatically reload whenever you modify the source code.

## 🏗️ Build

```bash
ng build
```

The build artifacts will be stored in the `dist/` directory.
